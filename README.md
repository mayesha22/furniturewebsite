## Built with
- HTML5
- Tailwind CSS v4
- Google Fonts (Cormorant Garamond)

## Getting started

### Dependencies
- Node.js — required to run Tailwind CSS
- A modern web browser (Chrome, Firefox, Safari)

### Installing
1. Clone the repository:
 ```bash
git clone https://github.com/mayesha22/furniturewebsite.git
```
2. Navigate into the project folder:
```bash
cd furniturewebsite
```

3. Install Tailwind CSS:
```bash
npm install tailwindcss @tailwindcss/cli
```

## Usage
1. Start the Tailwind watcher so your styles update as you make changes:
```bash
npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
```
2. Open `index.html` in your browser — no server required

## Pages
- **Home** — Landing page featuring a hero image and a call to action to view the latest collection
- **Seasonal Collection** —  Gallery showcasing key bedroom and bathroom spaces and designs
- **Showrooms** — Upcoming showroom listings for customers to attend across UK locations
- **About Us** — Brand story and our mission statement
- **Contact** — Customer enquiry form
